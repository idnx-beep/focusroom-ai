# FocusRoom AI QA Checklist

这份清单用于发布前手动验收。项目是前端作品集原型，数据只保存在浏览器 localStorage，不接后端、不接真实 AI API。

## Desktop

- [ ] 打开首页，确认背景场景、顶部导航、Hero 标题、CTA 和流程提示在首屏内层级清晰。
- [ ] 点击“开始专注”，确认可以进入自习室模式。
- [ ] 点击“先配置自习室”，确认页面滚动到控制台。
- [ ] 在控制台点击顶部流程按钮“1 选场景 / 2 写目标 / 3 开始专注”，确认分别切换场景面板、计划面板和进入自习室模式。
- [ ] 切换顶部导航中的“场景 / 音乐 / 计划 / 会员”，确认对应面板正常显示。
- [ ] 选择四个场景，确认右侧预览图、场景名称和背景图同步更新。
- [ ] 打开会员面板，确认 Demo / Coming soon 文案不会误导为真实付费能力。

## Mobile

- [ ] 在 375px 宽度检查首页，确认导航、标题、CTA、流程提示不横向溢出。
- [ ] 在 390px 宽度检查控制台，确认场景列表和右侧摘要上下排列，不出现横向滚动。
- [ ] 在移动端选择场景，确认卡片内容、标签和选中态可读，点击区域足够大。
- [ ] 在移动端打开计划面板，确认番茄钟按钮、目标输入框和开始按钮不拥挤。
- [ ] 在移动端进入自习室模式，确认倒计时不超出屏幕，暂停/继续/结束按钮可点击。
- [ ] 在移动端展开声音控制，确认控件可滚动、可点击、不遮挡主要倒计时。
- [ ] 在移动端打开复盘弹窗和分享卡片，确认弹窗不超出屏幕，内容可纵向滚动。

## Pomodoro Flow

- [ ] 在计划面板选择 25 / 45 / 50 / 90 分钟，确认倒计时显示同步更新。
- [ ] 点击“开始专注”，确认进入自习室模式并开始倒计时。
- [ ] 点击“暂停”，确认倒计时停止。
- [ ] 点击“继续”，确认倒计时继续。
- [ ] 点击“结束”，确认出现结束确认弹窗。
- [ ] 在结束确认弹窗点击“继续学习”，确认返回自习室且倒计时状态保留。
- [ ] 在结束确认弹窗点击“结束并复盘”，确认停止声音、退出自习室，并在有效学习超过 60 秒时打开复盘弹窗。
- [ ] 完成自然倒计时后，确认自动记录完整轮并进入复盘流程。
- [ ] 学习不足 60 秒手动结束，确认不会污染部分学习记录。

## Review And Share

- [ ] 在复盘弹窗填写“本轮完成了什么 / 遇到了什么问题 / 下一轮准备做什么”。
- [ ] 点击“保存复盘并生成卡片”，确认展示学习成果卡片。
- [ ] 点击“稍后再写”，确认仍能生成分享卡片，且不会保存空复盘为已完成。
- [ ] 点击“复制分享文案”，确认出现克制的复制成功 toast。
- [ ] 在浏览器禁用剪贴板权限时点击复制，确认出现失败提示。
- [ ] 回到控制台学习历史，点击“打开卡片”，确认可以重新打开分享卡片。
- [ ] 输入很长的目标和复盘内容，确认复盘弹窗、分享卡片、历史记录不会横向撑破。

## localStorage Refresh Restore

- [ ] 写入今日目标后刷新页面，确认目标保留。
- [ ] 切换场景后刷新页面，确认最后选择的场景保留。
- [ ] 修改番茄钟时长后刷新页面，确认时长保留。
- [ ] 修改声音类型和音量后刷新页面，确认声音设置保留。
- [ ] 开始一轮专注后刷新页面，确认正在进行的 session 恢复。
- [ ] 暂停一轮专注后刷新页面，确认暂停状态和剩余时间恢复。
- [ ] 复盘保存后刷新页面，确认最近学习历史保留。
- [ ] 清空浏览器 localStorage 后刷新页面，确认应用回到默认状态且不报错。

## GitHub Pages Deployment

- [ ] 确认 `vite.config.js` 中 `base` 为 `/focusroom-ai/`。
- [ ] 执行 `npm run build`，确认构建通过。
- [ ] 执行 `npm run preview`，访问 `/focusroom-ai/` 子路径，确认页面和静态资源正常加载。
- [ ] 执行 `npm run deploy` 发布到 `gh-pages` 分支。
- [ ] 在 GitHub Pages 设置中确认 Source 为 `Deploy from a branch`，Branch 为 `gh-pages`，目录为 `/ root`。
- [ ] 部署完成后访问 `https://idnx-beep.github.io/focusroom-ai/`，确认首页、控制台、自习室、复盘和分享卡片均可打开。
- [ ] 确认 `main` 分支未提交 `dist/`、`node_modules/`、zip 文件、`.DS_Store`、`.env` 或 `gh-pages` 分支构建内容。
